# 202605211200_baseline_read_v1

## Summary

Document the existing production read schema expected by the modern API as `baseline-read-v1`.

This artifact is the initial reference point for future schema changes. It does not introduce a new production mutation and must not be applied blindly to an existing production database.

## Compatibility

- Application version before migration: existing DTO-compatible deployment
- Application version after migration: modern API deployment with `/readyz` schema checks
- Backward-compatible before deploy: yes
- Requires `baseline-read-v1` readiness update: no

## Apply

No production apply step is required for this baseline artifact. The schema already exists before the modern API is routed to production traffic.

Reference schema for new empty environments:

```sql
CREATE TABLE unis (
  id serial PRIMARY KEY,
  title varchar(255),
  address varchar(255),
  "desc" varchar(255),
  lat double precision,
  long double precision,
  created_at timestamp,
  updated_at timestamp
);

CREATE TABLE grade_cs (
  id serial PRIMARY KEY,
  uni_id integer,
  cdepts_id integer,
  rate varchar(255),
  year varchar(255),
  created_at timestamp,
  updated_at timestamp
);

CREATE TABLE businesses (
  id serial PRIMARY KEY,
  cdepts_id integer,
  lat double precision,
  long double precision,
  title varchar(255),
  address varchar(255),
  created_at timestamp,
  updated_at timestamp
);

CREATE TABLE cbps (
  id serial PRIMARY KEY,
  total_indus double precision,
  total_anual double precision,
  cnaic integer,
  cnaic_name varchar(255),
  county integer,
  num_est integer,
  created_at timestamp,
  updated_at timestamp
);

CREATE TABLE muns (
  id serial PRIMARY KEY,
  title varchar(255),
  county integer,
  created_at timestamp,
  updated_at timestamp
);

CREATE TABLE cdepts (
  id serial PRIMARY KEY,
  cnaic integer,
  created_at timestamp,
  updated_at timestamp
);
```

## Verify

Read-only schema verification:

```sql
SELECT table_name, column_name
FROM information_schema.columns
WHERE table_schema = 'public'
AND table_name = ANY(ARRAY[
  'businesses',
  'cbps',
  'cdepts',
  'grade_cs',
  'muns',
  'unis'
])
ORDER BY table_name, ordinal_position;
```

Expected table and column coverage:

```text
businesses: id, cdepts_id, lat, long, title, address, created_at, updated_at
cbps: id, total_indus, total_anual, cnaic, cnaic_name, county, num_est, created_at, updated_at
cdepts: id, cnaic, created_at, updated_at
grade_cs: id, uni_id, cdepts_id, rate, year, created_at, updated_at
muns: id, title, county, created_at, updated_at
unis: id, title, address, desc, lat, long, created_at, updated_at
```

## Rollback

No schema rollback is required for this baseline artifact because it records the existing schema contract.

If readiness fails after deploying an app/API release that depends on this baseline:

```text
Route traffic to the previous app/API release pair and investigate the database schema mismatch before restoring traffic.
```

If production schema was changed outside this baseline, restore from the confirmed production backup or apply the reviewed rollback artifact for that later migration.
