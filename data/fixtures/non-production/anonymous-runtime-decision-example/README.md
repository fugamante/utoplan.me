# Anonymous Runtime Decision Example

This directory is a non-production fixture for validating the anonymous runtime production-decision artifact shape.

It is intentionally blocked:

- `exampleOnly`: `true`
- `productionApproval`: `false`
- `activationAllowed`: `false`
- `decisionStatus`: `blocked`

Do not use these files as production evidence or activation approval. Real decision artifacts must be stored with release evidence outside the public repository.
